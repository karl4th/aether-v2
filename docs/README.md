# aether — техническая документация

Статус: реализованы удалённый backend реальных весов, офлайн аудиодемо и ограниченная адаптация. `notebooks/aether_colab.ipynb` содержит Git checkout, установку, данные, inference с прослушиванием, оценку, pilot/resume и экспорт. Это готовность к ручному испытанию в Colab, не результат уже выполненного обучения. Локально модель и optimizer не запускались. Живые `serve`/`talk` ещё не реализованы.

Начинать работу с [единого плана задач](tasks.md): там находятся полный реестр, выполненные пункты, зависимости и критерии приёмки. Текущая машина используется только для разработки и ограниченных тестов. Всё обучение, включая короткие обучающие проверки, выполняется в удалённом runtime платного Google Colab через notebook; local runtime не используется.

## Статусы требований

- **Обязательно** — условие реализации и приёмки.
- **Начальная конфигурация** — выбранная отправная точка; изменение требует версии конфигурации и повторной оценки.
- **Эксперимент** — гипотеза, которую нельзя выдавать за готовую возможность.
- **Открытое решение** — недостающий выбор, необходимый перед соответствующим этапом.

При расхождении обзорного текста и подробного контракта применяются: `tasks.md` для статусов и распределения работ между локальной машиной и Colab, `specification.md` для области проекта, `model.md` для вычислений, `runtime.md` для транспорта, `development.md` для инструментов, `validation.md` для приёмки. Расхождение исправляется до реализации затронутого компонента.

## Текущая готовность

Документирован путь от проверки тензоров и аудиокодека до живого full-duplex разговора и контролируемого дообучения. Выбраны английский язык, демо чат-бота, Google Drive и бюджет первой стадии 500 юнитов. Комплект весов и корпус чтения закреплены в коде. Для всего сценария нужен A100 40 ГБ или больше; полученная T4 не подходит BF16-профилю. Поэтому наличие спецификации не означает готовность обучить систему с известным бюджетом или запустить голосовую модель одной командой.

Команды модели в документах — целевой интерфейс будущего приложения. `pyproject.toml`, группы зависимостей и `uv.lock` уже созданы. Проверки каркаса: `uv run --locked pytest`, `uv run --locked ruff check .`, `uv run --locked ruff format --check .`, `uv run --locked mypy src/aether`.

Схемы и ограничения описаны в [configuration.md](configuration.md). Выравнивание токенов реализовано без модельного backend; это не проверка качества речи. Для первого результата выбран начальный кодек, затем планируется кодек Manifestro с отдельной проверкой совместимости.

Локально реализованы [проверка артефактов](artifacts.md) и [аудиобуферы](audio.md); реальный state_dict, токенизатор и качество речи ещё не проверены.

Готов локально проверенный [полный notebook](../notebooks/aether_colab.ipynb) и [инструкция Colab](colab.md). A16/A17 остаются открытыми до удалённой проверки.
