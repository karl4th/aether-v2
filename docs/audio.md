# aether — аудиобуферы и временная сетка

`aether.audio` реализует mono PCM float32 little-endian. Пакет содержит 1–3840
отсчётов; NaN/Infinity, значения вне [-1,1] и неполные float32 отклоняются.
Пустой пакет не заменяется тишиной. `pop()` возвращает `None`, пока полного кадра нет.

`PCMBuffer` собирает кадры ровно по 1920 отсчётов (80 мс при 24000 Гц).
`AudioFrame` содержит индекс, sample_offset и PCM bytes. Границы пакетов не влияют
на байты кадров. Очередь хранит не больше max_queue_frames полных кадров и одного
неполного хвоста. Входящий пакет целиком принимается или целиком отклоняется с
`BufferError`; ранее принятые отсчёты сохраняются. Число переполнений учитывается.
После каждого push потребитель извлекает кадры через pop; длительная перегрузка
должна завершать будущую runtime-сессию, а не удалять аудио из середины очереди.

Счётчики: received_samples, emitted_samples, padded_samples, discarded_samples,
accepted_packets, overflow_count и buffered_samples. Для принятого звука:
`received + padded = emitted + buffered + discarded`.

`finish(pad=False)` закрывает вход, учитывает и отбрасывает только неполный хвост;
полные кадры остаются для чтения. Для offline разрешён `finish(pad=True)`: хвост
дополняется нулями, количество дополнений фиксируется. Если очередь заполнена,
сначала надо извлечь готовые кадры, затем повторить finish. `reset()` полностью
очищает данные, счётчики и закрытое состояние. Runtime stop должен использовать
reset, когда необходимо удалить также все готовые кадры.

`resample_pcm` — эталонное офлайн-преобразование целой записи оконным sinc-фильтром
с антиалиасингом при понижении частоты. Поддерживаются целые частоты 8000–192000 Гц.
Длина результата `ceil(N * target/source)`; края продолжаются ближайшим отсчётом.
Выход ограничен [-1,1] после возможного выброса фильтра. При совпадении частот
байты сохраняются. Это не потоковый ресемплер: нельзя применять его независимо
к сетевым пакетам. Транспорт первой версии принимает только 24000 Гц. Ресемплинг
устройства, компенсация drift и качество реальной речи ещё не проверены.

Тесты проверяют случайные границы пакетов, точную сохранность PCM, счётчики,
переполнение, хвост, reset, независимость буферов, DC, длину и частотный отклик
на синтетических сигналах. Микрофон, кодек, модель и обучение не запускаются.
